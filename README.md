### Project Overview

This project explains three fundamental concepts of Linear Algebra: Span, Basis and Dimension through mathematical animations created using Python and Manim.

The objective is to help students understand how vectors generate a subspace, how a basis represents a minimal linearly independent spanning set, and how dimension measures the number of independent basis vectors.

### Learning Objectives

By the end of this animation, viewers should understand:

1. The meaning of span and linear combinations.
2. The relationship between linear independence and basis.
3. How dimension describes the number of vectors in a basis.

### Animation Structure

1. Hook and Context
2. Concept Introduction
3. Visual Intuition
4. Worked Example
5. Mathematical Interpretation
6. Summary and Credits
